# Edubits v2.0 — Project Requirements

## 1. Overview

Edubits is an all-in-one academic toolkit for Chandigarh University engineering students. It links to every resource a student needs in one place, so they can prepare for exams and manage college life. It is a practical way to survive college, built from the founder's own experience.

Live (v1): https://edubits-ten.vercel.app

## 2. Target users

| Group | Scope |
|-------|-------|
| BE CSE | Years 1–4 |
| BE CSE (AIT) | 3rd year only — Data Science and AIML specializations |

Roles: `user` and `admin`. Admins upload and manage resources; everyone else consumes them.

## 3. Goals and success metrics

**Goals**
- One place to prepare for exams and manage college life.
- Resources section fully complete before end-term exams (15-day window from 2026-10-20).

**Metrics**
- Active users
- Page views

## 4. Scope

## 5. Requirements by area

### 5.1 Homepage
- Logged-out homepage is a preview only, with login/register.
- Remove the "Get Started" button; Login and Register buttons sit below the headline.
- Sign in with Google on login and register, plus GitHub and Microsoft.
- Tools split into two groups:
  - Popular / most used — Exam prep: Resources and QuizEngine
  - Other tools — calculators and Task Tracker
- Remove Engineering Tracker from the homepage.
- Footer moves to a separate page, with a professional footer and components.
- Onboarding for new users.

### 5.2 Resources / Exam prep
- Top level is year; inside each year, subjects; inside each subject, PYQs, playlists and notes.
- Remove the Revision tab.
- In-browser PDF viewer that keeps users on the site instead of embedding Google Drive.
- Every PYQ has a solution, delivered as a PDF created by the admin.
- Each paper appears as two PDF cards: one with the questions only, one with questions and solution.
- In-site viewer is a must-have: Cloudinary for file storage, react-pdf for the viewer.
- Admins upload content through a dashboard UI.
- Improve usability of the notes section.

### 5.3 QuizEngine
- Remove the graph view.
- Two modes: college subjects (viva) and NPTEL preparation.
- Cards use a subject-relevant photo instead of icon text and description.
- Add PYQ-based and LLM-generated MCQs for variety.
- Questions are generated by the admin beforehand and fed in as JSON per subject.

### 5.4 SGPA + CGPA calculators
- Remove "Export to PDF" from the CGPA calculator.
- Mini cards instead of three big blocks.
- Credits as a dropdown (1–6).
- "Qualified" grade option for non-graded subjects: passing shows "Qualified", failing shows "Fail" and the student must reappear. Neither outcome affects SGPA or CGPA, so these subjects are ignored in credit and weight calculation. Placed at the top of the grade list as the default value.
- "Clear all" button in the CGPA calculator.
- Remove the feedback line "Down 1.30 from last semester. Recoverable."
- Explain jargon to users; use current-semester credits, not next-semester.

### 5.5 Internal Marks calculator
- Top level has two options: BE CSE (default) and BE CSE (AIT).
- Add 3rd-year general CSE.
- Extend to the AIT specialization.
- Explain Hybrid, Theory and Practical subjects with example subject names.
- Improve the overall look and feel.

### 5.6 Task Tracker
- Current implementation is messy and needs a full rework.
- Deadline-first design.
- Needed workflow: list pending tasks with deadlines, schedule work before each deadline, and see a clear "deadline near" or "deadline missed" indicator.
- Kanban columns stay as a secondary view.

## 6. Cross-cutting requirements

- **Auth:** email/password and Google OAuth, plus GitHub and Microsoft.
- **Persistence:** anything that must persist (PYQ progress, notes, tasks) goes to MongoDB. SGPA/CGPA and Internal Marks stay client-side.
- **Performance:** every route lazy-loaded; chunk and image size limits.
- **Analytics:** capture active users and page views.

## 7. Constraints

- 15 days from 2026-10-20; Resources must be done before end-term exams.
- Stack unchanged.
- Every new dependency needs the owner's approval.
- Work stays on a branch until ready to ship.
